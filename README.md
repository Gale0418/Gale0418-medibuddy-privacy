# 小熊叮嚀隱私權政策

這個 repository 用於公開存放小熊叮嚀的隱私權政策頁面，供 Apple App Store、Google Play 商店審核與使用者查閱。

目前政策涵蓋 iOS 與 Android 的裝置本機資料、Email Policy V2（連續 48 小時未開 App 的固定通知）、問題回報、推薦邀請、首筆非零實付資格與平台商店訂閱驗證。Apple App Store 隱私權標示已同步為電子郵件地址、其他使用者內容、裝置識別碼、購買記錄與其他診斷資料；全部只用於 App 功能、與使用者身分連結且不追蹤。各功能是否提供，以使用者目前安裝版本的 App 畫面為準。

正式版本目前不提供 OCR，也不會透過「小熊幫你看」上傳圖片。LINE 與 SMS 自動通知尚未提供；LINE 僅可由使用者透過系統分享面板自行傳送推薦連結。
